# Minimalist-3D-Interactive-Story-Website
Convalt Energy's minimalist 3D WebGL interactive storytelling website. Inspired by mont-fort.com, it features scroll-driven 3D scenes for solar manufacturing, utility grid power, green data hubs, and circular recycling. Engineered with Three.js, GSAP, and Web Audio API, pairing immersive WebGL with a responsive 2D corporate suite running at 60 FPS.
